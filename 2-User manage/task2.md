
# Запрещаем

1. Запретите пользователю user1 из предыдщуего задания выполнять вход в систему

usermod -L user1

2. Как вы это сделали?

Команда usermod -L блокирует пользователя.

3. Какие ещё способы это сделать вы знаете?

Удаление пароля: sudo passwd -l user1

Отключение учетной записи: sudo usermod --expiredate 1 user1 Учетная запись блокируется, как если бы её срок действия истёк.

Изменение shell на /sbin/nologin: sudo usermod -s /sbin/nologin user1 Пользователь не сможет выполнить вход, так как его оболочка будет недоступна.

4. Можно ли создать пользователей с одинаковыми username?

Нет, создание пользователей с одинаковыми именами (username) невозможно, они должны быть уникальны.
