# Скриптуем по полной

На скринах

1. Что такое шебанг?

Shebang (#!), первый строка в скриптах Bash (и некоторых других), указывает интерпретатору, который должен использоваться для выполнения скрипта.

Пример: #!/bin/bash - говорит системе использовать bash для интерпретации кода.

2. Обязательно ли исполняемый файл дожен иметь соотвествующее расширение?

Нет, не обязательно.  Расширение файла (например, .sh) может быть любым, но shebang  - это то, что указывает операционной системе, как интерпретировать скрипт.

Хотя можно обойтись без расширения, в большинстве систем принято использовать .sh для скриптов Bash, чтобы облегчить их идентификацию.

3. Напишите скрипт который выполнит автоматически действия из блока работы с файлами. ( не забудьте включить set -euo pipefail для того что бы ваш скрипт было удобнее отлаживать. Опишите что включают эти флаги)

set -e: Если любая команда в скрипте завершается неуспешно (возвращает код выхода отличным от 0), скрипт будет немедленно прерван. Это помогает обнаружить ошибки и предотвратить дальнейшую обработку данных, которые могут быть повреждены.

set -u: Заставляет скрипт выдавать ошибку, если используется переменная, которая не определена. Помогает избежать неожиданных ошибок из-за использования неинициализированных переменных.

set -o pipefail: Если команда в pipeline (последовательность команд, связанных символом |) завершается неуспешно, то скрипт будет прерван.
