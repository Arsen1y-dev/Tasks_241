# Продолжаем

1. Raid массивы, что такое икакие бывают

RAID (Redundant Array of Independent Disks) — это технология, объединяющая несколько физических дисков в один массив для повышения производительности, отказоустойчивости или объёма хранилища.

Типы RAID массивов:

    RAID 0 (Striping):
        Данные радыспределяются между дисками без дублирования.
        Преимущества: высокая скорость чтения и записи.
        Недостатки: при сбое одного диска теряются все данные.

    RAID 1 (Mirroring):
        Данные полностью дублируются на всех дисках.
        Преимущества: высокая отказоустойчивость.
        Недостатки: использование 50% объёма (из двух дисков один используется как копия).

    RAID 5 (Striping with Parity):
        Данные распределяются между дисками с добавлением информации о чётности.
        Преимущества: баланс между производительностью и отказоустойчивостью.
        Требует минимум 3 диска.

    RAID 10 (1+0):
        Сочетание RAID 1 и RAID 0.
        Преимущества: высокая производительность и отказоустойчивость.
        Требует минимум 4 диска.

7. Есть ли файловые системы которые поддерживают raid массивы без стороненго ПО

Да, такие файловые системы существуют. Например, Btrfs и ZFS поддерживают RAID массивы без необходимости использования стороннего ПО.

8. Можно ли создать raid массив во время установки системы?

Да, большинство современных дистрибутивов Linux позволяют создать RAID массив во время установки системы. Это можно сделать через установочный интерфейс, выбрав соответствующие опции для настройки RAID.
