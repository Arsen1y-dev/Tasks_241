# Ключики

1. Что такое ssh ключи и зачем они нужны?

SSH-ключи — это метод аутентификации, который позволяет вам подключаться к серверам SSH без необходимости вводить имя пользователя и пароль.

2. Как их создать? 

Создаются они с помощью команды ssh-keygen. Параметр -t отвечает за тип ключа ([-t dsa | ecdsa | ecdsa-sk | ed25519 | ed25519-sk | rsa]).

4. Скопируйте публичный ключ на ваш сервер, в каком файле он будет храниться?

Чтобы скопировать публичный ключ на сервер:

ssh-copy-id username@server_ip  

Эта команда автоматически добавит содержимое публичного ключа в файл ~/.ssh/authorized_keys на сервере.
