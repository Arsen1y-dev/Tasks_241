# Конфижим для удобства

На скринах

1. Где хранятся пользвательские и системные настройки подключения?

Пользовательские настройки: /etc/openssh/ssh_config 
Системные настройки: /etc/openssh/sshd_config

2. Что за файл options?

Файл options обычно находится в папке .ssh в домашней директории пользователя. Он содержит параметры для соединения SSH (Secure Shell), включая имя хоста, порт и другие настроики.

3. Отредактируйте файл options так, чтобы можно было подключаться не вводя имя пользвателя и порт

4. Назовите подключение удобным для вас спсобом

5. Проверьте работоспособность
