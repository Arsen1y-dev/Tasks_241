6. Что такое ip адрес?

IP-адрес (Internet Protocol Address) — это уникальный числовой идентификатор устройства в сети. Он необходим для идентификации и связи устройств. Существует два основных формата IP-адресов:
	•	IPv4 (например, 192.168.1.1),
	•	IPv6 (например, 2001:0db8:85a3:0000:0000:8a2e:0370:7334).

7. Для чего нужны маршруты?

Маршруты указывают, через какие сети или устройства передавать пакеты данных, чтобы они достигли нужного получателя. Маршрутизация позволяет устройствам взаимодействовать в сложных сетях, таких как интернет, через использование таблиц маршрутизации.

8. Что за протокол arp?

ARP (Address Resolution Protocol) — это протокол, который связывает IP-адрес устройства с его физическим (MAC) адресом в локальной сети. Например, зная IP-адрес компьютера в сети, ARP помогает узнать его MAC-адрес для отправки данных.

9. Что такое dhcp?

DHCP (Dynamic Host Configuration Protocol) — это протокол, который автоматически назначает сетевые настройки устройствам в сети, включая:
	•	IP-адрес,
	•	Маску подсети,
	•	Шлюз по умолчанию,
	•	Адрес DNS-серверов.

10. Что такое dns?

DNS (Domain Name System) — это система, которая преобразует доменные имена (например, example.com) в IP-адреса, понятные устройствам в сети. Это позволяет пользователям обращаться к ресурсам через удобные имена вместо числовых адресов.

11. Как называется один из протоколов синхронизации времени?

Один из самых популярных протоколов для синхронизации времени — это NTP (Network Time Protocol). Он позволяет устройствам поддерживать точное время, синхронизируясь с серверами времени.

12. Что такое широковещательный запрос, зачем он нужен?

Широковещательный запрос (broadcast) — это сообщение, отправленное всем устройствам в сети одновременно. Оно используется для поиска устройств, назначения IP-адресов (DHCP) или получения информации от неизвестного уз

13. Какой адресс является широковещательным?

В IPv4 широковещательным адресом является последний адрес в подсети. Например, для подсети 192.168.1.0/24 широковещательный адрес — 192.168.1.255. Он применяется для отправки сообщений всем устройствам в подсети.

14. Какие ещё параметры можно задать сетевой карте?

Сетевой карте можно задать:
	•	IP-адрес,
	•	Маску подсети,
	•	Шлюз по умолчанию,
	•	DNS-серверы,
	•	MTU (максимальный размер пакета),
	•	MAC-адрес (иногда возможно его изменение),
	•	Включение/выключение режима DHCP.

15. Что такое маска подсети? зачем она нужна?

Маска подсети — это параметр, определяющий, какая часть IP-адреса относится к сети, а какая — к устройству. Например, маска 255.255.255.0 указывает, что первые три октета IP-адреса определяют сеть, а последний — устройство. Маска нужна для разделения сетей и управления маршрутизацией.
